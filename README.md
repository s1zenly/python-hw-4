# Сервис обращений абонентов

Простой сервис на FastAPI и Pydantic: принимает обращение, проверяет поля и сохраняет его в `data/appeals.json`.

## Структура

- `main.py` — точка входа.
- `app/api.py` — эндпоинты FastAPI.
- `app/validation.py` — модель Pydantic и валидаторы.
- `app/logic.py` — сохранение и выдача обращений.
- `app/db.py` — чтение и запись JSON-файла на диске.

## Что проверяется

- **Фамилия** и **имя** — с заглавной буквы, только кириллица, без цифр и спецсимволов.
- **Дата рождения** — формат `ГГГГ-ММ-ДД` или `ДД.ММ.ГГГГ`, не в будущем и не старше 120 лет.
- **Телефон** — российский номер `+7XXXXXXXXXX` или `8XXXXXXXXXX`. В файл пишется номер в виде `+7XXXXXXXXXX`.
- **E-mail** — адрес вида `name@example.com`.
- **Причины** — одна или несколько из списка: `не приходят письма`, `нет доступа к сети`, `не работает телефон`.
- **Дата и время обнаружения проблемы** — не в будущем и не раньше даты рождения. Форматы: `ГГГГ-ММ-ДДTЧЧ:ММ:СС`, `ДД.ММ.ГГГГ ЧЧ:ММ`.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

Документация и форма запроса: http://127.0.0.1:8000/docs

## Пример запроса

```bash
curl -X POST http://127.0.0.1:8000/appeals \
  -H "Content-Type: application/json" \
  -d '{
    "фамилия": "Иванов",
    "имя": "Иван",
    "дата_рождения": "1990-05-15",
    "телефон": "+79001234567",
    "email": "ivan@example.com",
    "причины": ["не приходят письма", "нет доступа к сети"],
    "дата_время_обнаружения": "2026-11-01T14:30:00"
  }'
```

Сохранённые обращения: `GET http://127.0.0.1:8000/appeals` и файл `data/appeals.json`.
